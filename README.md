# 🔥 V R FITNESS — Transform Your Body. Elevate Your Life.

**A modern, interactive gym website built for fitness enthusiasts who believe in pushing limits and achieving more.**

V R Fitness is a bold and immersive gym website concept featuring a sleek dark interface, neon-inspired visuals, smooth animations, an interactive AI Fitness Coach demo, and membership plans.

Designed to bring the energy of a premium fitness club into a digital experience. 💪

---

## ⚡ Project Highlights

- 🖤 **Premium Dark UI** — A modern matte-black interface with neon red and electric blue accents.
- 🎬 **Dynamic Hero Section** — Background workout video with animated headlines and call-to-action buttons.
- 🤖 **AI Fitness Coach Demo** — An interactive chat interface for workout suggestions, nutrition tips, and basic fitness-related questions.
- 🏋️ **Membership Plans** — Three membership options: Basic, Premium, and Elite.
- 📝 **Interactive Registration** — Select a membership plan and enter your name and email through a registration modal.
- ✨ **Smooth Animations** — Motion effects and transitions powered by Framer Motion.
- 📱 **Responsive Layout** — Designed to adapt to different screen sizes.
- 💎 **Glassmorphism Effects** — Modern translucent cards and blurred backgrounds.

## 🚀 Getting Started

Want to explore V R Fitness on your own computer? Follow these simple steps.

**1. Clone the repository**

```bash
git clone https://github.com/shree451-gym/shree451-gym.git
```

**2. Open the project folder**

```bash
cd shree451-gym
```

**3. Run the website**

Open `gym.html` in your browser.

That's it! You're ready to explore V R Fitness. 🎉

*Note: An active internet connection is required to load the external CDN libraries, Google Fonts, and background video.*

## ⚠️ Demo & Integration Notes

This project currently uses simulated backend responses to demonstrate the user experience.

- **AI Fitness Coach:** Uses predefined JavaScript responses. It is not connected to a real AI model or Python API.
- **Membership Registration:** Generates a demo member ID and confirmation message. It does not process real payments or save member details to a database.
- **Backend Architecture:** Python FastAPI, Java Spring Boot, and MySQL are mentioned as simulation concepts in the code, but are not actually integrated.
